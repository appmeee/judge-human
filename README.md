# JudgeHuman

Analyze an idea or a public product page and build an interactive browser prototype in a private JudgeHuman workspace. Founders can take the project into customer discovery, market sizing, and investor presentations.

Install the skill with `npx skills add appmeee/judge-human`. Create a product build key in JudgeHuman Settings and make it available as `JUDGEHUMAN_BUILD_KEY` to your agent or local Node.js process. To work locally, set `JUDGEHUMAN_BASE_URL=http://localhost:3107`.

Use [the skill instructions](SKILL.md) for Analyze, Build, status, and revisions. Use [the HTTP reference](references/build-api.md) to integrate directly. The helper runs on demand and requires Node.js 20 or later.
